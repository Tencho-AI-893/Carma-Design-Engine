# Media AutoPilot - イチゴナビ（求人）自動化

イチゴナビ（15navi）のスカウト送信と面接管理を1画面で行うデスクトップアプリです。
`15navi-offer` リポジトリの `send_offers.mjs`（CLIスクリプト）をGUIアプリとして再構築したものです。

## 機能

- **スカウト**: 生成 → 内容確認 → 選んで送信
  - 「下書きを生成」でリストページを巡回し、会員ごとに件名/本文の下書きを作成
  - テーブルで内容を確認し、選択した下書きだけを送信（送信前に確認ダイアログ）
  - dry-runモード（既定ON）では実送信せず対象の確認のみ
  - 1日の送信上限（既定30件）・送信済み/受信上限の自動スキップ・3〜5秒のランダム待機
- **面接管理**: 設定→来店の歩留まりを追跡
  - 面接を登録し、リマインド済/来店/飛び/採用のステージを更新
  - 設定済・来店数から歩留まり%を自動集計
- **定期更新(bump)**: 指定間隔（既定30分）で掲載更新ボタンを自動クリック
- **ログ**: すべての操作を画面とファイル（userData/logs/）に記録

## セットアップ

```bash
cd media-autopilot
npm install
npx playwright install chromium
npm start
```

## 使い方

1. **設定タブ** でログインURL・ID・パスワード、メッセージテンプレ等を保存
   （テンプレ内の `{name}` は会員名に置換されます）
2. **ブラウザ起動ログイン** → 表示されたブラウザでログインを完了 → **ログイン完了** を押す
   （セッションが保存され、以降の操作はバックグラウンドで実行）
3. **下書きを生成** → テーブルで内容確認 → 行を選択して **選択を送信（確認）**
4. 面接が決まったら **面接を登録**、当日の結果に応じて **来店 / 飛び / 採用** を押す

## データの保存場所

設定・下書き・面接データ・ログイン状態はElectronのuserDataディレクトリに保存されます
（Windows: `%APPDATA%/media-autopilot/`）。パスワードを含むため取り扱いに注意してください。

## 他のPCへ配布する（インストーラー作成）

Windows PC上で以下を実行すると、`dist/` フォルダに配布用ファイルができます。

```bash
cd media-autopilot
npm install
npm run dist
```

- `Media AutoPilot Setup 1.0.0.exe` … インストーラー（他のPCにコピーしてダブルクリックでインストール）
- `Media AutoPilot 1.0.0.exe` … ポータブル版（インストール不要、USBメモリ等で持ち運び可）

配布先のPCでは、初回起動前に一度だけChromium（自動操作用ブラウザ）が必要です。
インストーラー版・ポータブル版どちらでも、初回に「ブラウザ起動ログイン」が失敗する場合は
配布先PCで `npx playwright install chromium` を実行してください。

> 注意: 設定に保存したログインID/パスワードは各PCのローカル（userData）に保存されます。
> アプリ本体（exe）には含まれないので、配布先のPCごとに設定タブで入力してください。
