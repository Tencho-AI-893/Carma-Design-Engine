# 金融リテラシー＝人として｜ブランドOS

> 金融リテラシーは、お金の知識ではない。
> 人生の選択肢を増やす力である。

> **統合命題：予測を手放し、規律を掲げる。**
> 市場について断言しない。原則については誰よりも断言する。（→ `11_dialectic.md`）

このディレクトリは、ブランド「金融リテラシー＝人として」の**設計図**です。
コンテンツそのものではなく、**コンテンツを10年間ブレずに生み出し続けるための仕組み（OS）**を管理します。

---

## このOSが解く課題

個人の発信は、たいてい次の理由で3年以内に価値が止まります。

| 止まる理由 | このOSでの対処 |
|---|---|
| 相場が良いときだけ発信が続く | 運用リズム（`08`）で相場に依存しない周期を固定 |
| 予想が外れて発信できなくなる | 事前公開ルール（`03`）で「外れ」も想定内の記録に変える |
| 過去の発言と矛盾する | 判断ログ・ルール変更ログ（`templates/`）で変更を資産化 |
| 法令表現でヒヤリとして萎縮する | 表現ガイド（`04`）で安全な言い換えを標準装備 |
| 単発コンテンツが積み上がらない | コンテンツ設計（`05`）で一次資産→二次展開に一本化 |
| 数字を追ってブランドが崩れる | KPI設計（`09`）でブランド資産側の指標を主指標に置く |

## 使い方（発信前の3ステップ）

1. **書く前**：`02_editorial-policy.md` の「8つの判断基準チェックリスト」を通す
2. **書いた後**：`04_compliance-guide.md` の「表現セルフチェック」を通す
3. **公開後**：判断を伴う行動をしたら `templates/decision-log.md` に記録する

この3つを回すだけで、コンテンツは「投稿」ではなく「資産」になります。

## 重要な前提

- 本ディレクトリの内容は、特定の金融商品の売買を推奨するものではありません。
- 法令に関する記述（`04`）は一般的な整理であり、法的助言ではありません。実際の事業判断は必ず専門家に確認してください。
