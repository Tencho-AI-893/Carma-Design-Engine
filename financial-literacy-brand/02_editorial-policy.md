# 02. 編集方針

理念は、毎回の一文にまで落ちて初めて意味を持つ。
このファイルは、**書くときに開くファイル**。

---

## 1. 発信の原則

> 発信は常に、**「予想」ではなく「検証」**である。

- 未来を断言しない
- 利益を保証しない
- 成功だけを見せない

**金融リテラシーを身につける過程そのものを価値として発信する。**

---

## 2. 8つの判断基準チェックリスト

すべての企画・投稿・商品は、公開前にこれを通す。
**3つ以上「いいえ」なら、出さずに設計し直す。**

| # | 基準 | 具体的な問い |
|---|---|---|
| 1 | 長期でブランド価値が積み上がるか | 3年後に読まれても恥ずかしくないか |
| 2 | 金融リテラシーの理念に沿っているか | 「稼ぐ・守る・増やす・使う・残す」のどれかに接続するか |
| 3 | 初心者でも理解できるか | 専門用語に、初出時の説明があるか |
| 4 | 再現性があるか | 読者が自分の状況に置き換えて実行できるか |
| 5 | 法令・規制に配慮した表現か | `04_compliance-guide.md` のセルフチェックを通したか |
| 6 | コンテンツとして資産化できるか | 単体で完結し、後から参照・再編集できるか |
| 7 | 「考え方」と「仕組み」を提供できているか | 結論だけでなく、そこに至る手順を渡しているか |
| 8 | 単発ではなく10年育つ設計か | シリーズ・記録・体系のどこに位置づくか説明できるか |

### 特に落としやすい基準

- **基準4（再現性）**：「私はこう考えた」で終わると読み物にしかならない。
  必ず「あなたの場合はここを見る」まで書く。
- **基準8（10年）**：バズを狙った単発は、基準8で必ず落ちる。落として良い。

---

## 3. トーン＆マナー

### 基本の声

- **一人称は「私」**。「僕」「俺」は使わない（10年後も age しない）。
- **断定は自分の判断に対してのみ**。市場・他人・未来には使わない。
- **感嘆符は原則使わない**。テンションではなく内容で読ませる。
- **煽り見出しを使わない**。「知らないと損」「絶対に」「今すぐ」は禁止。

### 文章の型

```
1. 結論（今回わかったこと・決めたこと）
2. 前提（そのとき何を知っていたか）
3. 判断（なぜそう決めたか＝考え方）
4. 実行（何をしたか＝事実）
5. 検証（結果と、想定とのズレ）
6. 次（次回の検証テーマ）
```

この6ブロックは、月次レポートにもX投稿にもYouTube台本にも使える。
**型を固定するから、10年書ける。**

## 4. 語彙定義（このブランドの言葉）

言葉の意味を固定する。ブレると世界観が壊れる。

| 用語 | 定義 | 使い方の注意 |
|---|---|---|
| **金融リテラシー** | 稼ぐ・守る・増やす・使う・残すの5領域を通じて、人生の選択肢を増やす力 | 「投資の知識」の意味では使わない |
| **実践者** | 専門家ではなく、自分の資金で検証し、過程を公開する立場 | 「プロ」「先生」と自称しない |
| **検証** | 事前に立てた仮説とルールを、実際の運用で確かめること | 「予想」と混同しない |
| **仮説** | 正しいかどうかまだわからない前提 | 必ず「仮説」と明記する |
| **記録** | 損益・判断・感情を含む、事実の保存 | 良い記録だけを記録と呼ばない |
| **ルール** | 事前に決め、公開してある行動基準 | 事後に語る方針は「ルール」と呼ばない |

## 5. 使わない表現 / 言い換え辞書

**理念上も法令配慮上も、次の言い換えを徹底する。**

| ❌ 使わない | ⭕ 言い換える |
|---|---|
| 上がります / 下がります | 私は◯◯という仮説を置いています |
| おすすめ銘柄 | 私が検証対象にしている資産 |
| 買うべき | 私は自分のルールに従ってこう判断しました |
| 儲かります | 過去にはこういう結果でした（将来を示すものではありません） |
| 絶対に / 確実に | 現時点の私の理解では |
| 初心者でも簡単に稼げる | 初心者が判断の型を身につける |
| 今しかない / 今すぐ | 私は今回、このタイミングで実行しました |
| million円になりました（利益強調のみ） | 損益と、判断の当たり外れをセットで公開 |

> 判断に迷ったら原則：**「主語を市場から自分に戻す」**。
> 市場を語ると予想になり、自分を語ると検証になる。

---

## 6. 失敗の公開ルール

失敗公開は、ブランドの信頼を作る最重要資産。ただし**型がないと、ただの反省文**になる。

必ず `templates/failure-log.md` の型で書く。要点は3つ。

1. **感情を書くが、感情で終わらせない**（何を感じたか → 何を変えるか）
2. **他責にしない、しかし自責もしすぎない**（構造の問題として書く）
3. **必ず「次のルール変更」に接続する**（学びが仕組みに変わって初めて資産）

---

## 7. コメント・批判への対応方針

| 状況 | 対応 |
|---|---|
| 事実誤認の指摘 | 速やかに訂正し、訂正した事実も残す（削除しない） |
| 手法への批判 | 「仮説であること」を再確認し、反証として記録に加える |
| 予想を求められる | 「予想はしません。私のルールはこうです」と返す（定型） |
| 個別の投資判断を求められる | 個別助言はしない旨を明示（→ `04_compliance-guide.md`） |
| 誹謗中傷 | 反応しない・削除で対応。議論の記録は残さない |

**訂正記録を残すことが、このブランドでは「弱さ」ではなく「証拠」になる。**
