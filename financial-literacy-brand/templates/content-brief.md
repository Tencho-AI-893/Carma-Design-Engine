## 8つの判断基準チェック（`02`）

- [ ] 1. 長期でブランド価値が積み上がるか
- [ ] 2. 金融リテラシーの理念に沿っているか
- [ ] 3. 初心者でも理解できるか
- [ ] 4. 再現性があるか
- [ ] 5. 法令・規制に配慮した表現か
- [ ] 6. コンテンツとして資産化できるか
- [ ] 7. 「考え方」と「仕組み」を提供できているか
- [ ] 8. 単発ではなく10年育つ設計か

**「いいえ」が3つ以上 → 出さずに設計し直す**

## 表現セルフチェック（`04`）

- [ ] 未来の値動きを断定していない
- [ ] 「必ず」「絶対」「確実」「保証」を使っていない
- [ ] 特定商品の売買を指示する形になっていない
- [ ] 実績を出す場合、損失・条件・期間も併記した
- [ ] PR・アフィリエイトがある場合、冒頭で明示した
- [ ] 末尾に免責文を入れた
