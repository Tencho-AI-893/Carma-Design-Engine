# 判断ログ テンプレート

> 判断を伴う行動をしたら、**その日のうちに**書く。
> 後から書くと、記憶が結果に合わせて書き換わる（後知恵バイアス）。
> これを避けること自体が、金融リテラシーの実践。

## 事後評価（1〜3ヶ月後に追記）

| 項目 | 内容 |
|---|---|
| **評価日** | YYYY-MM-DD |
| **結果** | |
| **4象限分類** | ①再現性あり／②想定内の損失／③危険な成功／④明確な失敗 |
| **判断は妥当だったか** | （結果ではなく、判断のプロセスを評価する） |
| **ルールを変える必要があるか** | あり → `rule-change-log.md` へ ／ なし |

> **重要**：結果が良くても、プロセスが悪ければ「良い判断」ではない。
> ここを分けて評価できることが、このブランドが教える最大のリテラシー。
