# 03. 検証プロトコル（ブランドの証明装置）

このファイルが、このブランドの**最大の差別化要因**。

---

## 1. なぜプロトコルが必要か

「予想しません、検証します」と言うだけなら、誰でも言える。
問題は、**それを外部から検証できる形にできているか**。

事後に「こう考えていた」と語る発信者と、
事前に「こう決めた」と公開してある発信者は、**まったく別の資産価値**を持つ。

このブランドは後者を選ぶ。そのための規約が以下。

---

## 2. 3つの原則

### 原則1：事前公開（Pre-Registration）

**判断ルールは、実行の前に公開する。**

- 積立ルール、利確ルール、損切りルール、リバランス基準を事前に文書化
- 公開日時が記録に残る形（投稿・コミット等）で出す
- 実行後に「実はこう決めていた」は認めない

> これは科学における「事前登録」の考え方の応用。
> 結果を見てから基準を決めれば、どんな結果も成功に見せられる。それをしない宣言。

### 原則2：全記録（Full Record）

**都合の悪い記録も、良い記録と同じ形式で残す。**

- 損失も利益と同じフォーマットで公開
- 「やらなかった判断」も記録する（見送りは判断である）
- 感情の記録も残す（後から読むと、最も学びが大きいのはここ）

### 原則3：変更の透明化（Documented Change）

**ルールは変えていい。ただし、必ず理由と一緒に。**

変更時に記録する4点：

1. 何を変えたか（変更前 → 変更後）
2. なぜ変えたか（どの事実・経験が根拠か）
3. いつから適用するか
4. この変更で何が改善されると考えているか

→ `templates/rule-change-log.md`

**禁止事項**：損失を回避するための事後的なルール変更（＝後付けの正当化）。
やむを得ず行う場合も、「これは事後変更である」と明記する。

---

## 3. 検証サイクル

```
① 仮説を立てる
   「Bitcoinには約4年周期の価格サイクルがあるのではないか」
        ↓
② 仮説を反証可能な形にする
   「もしサイクル仮説が誤りなら、◯◯という現象が観測されるはず」
        ↓
③ ルールを事前公開する
   積立額・頻度・利確条件・損切条件・例外条項を文書化して公開
        ↓
④ 実行し、全記録する
   判断ログ・損益・感情・見送った判断
        ↓
⑤ 定期的に照合する（月次）
   仮説どおりか / ズレているか / ルールを守れたか
        ↓
⑥ 学びを抽出し、必要ならルールを変更（理由付きで公開）
        ↓
   ①に戻る
```

**重要**：⑤で見るのは「儲かったか」ではなく、
**「ルールを守れたか」と「仮説はまだ生きているか」**の2点。
損益はその結果であって、評価軸ではない。

---

## 4. 仮説の書き方（テンプレート）

```markdown
### 仮説 H-001
- **内容**：（何が起きると考えるか）
- **根拠**：（なぜそう考えるか／過去データ・構造的理由）
- **反証条件**：（何が観測されたらこの仮説は誤りと判断するか）★必須
- **検証期間**：（いつまで見るか）
- **この仮説に賭ける資金の上限**：（総資産に対する％）
- **公開日**：YYYY-MM-DD
```

**反証条件がない仮説は、仮説ではなく信仰。**
このブランドでは、反証条件のない仮説を公開しない。

---

## 5. 検証結果の4分類

結果は必ずこの4象限で語る。「当たった/外れた」の二元論を使わない。

|  | ルールを守った | ルールを破った |
|---|---|---|
| **結果が良い** | ① 再現性あり（最も価値ある結果） | ③ 危険な成功（最も警戒すべき結果） |
| **結果が悪い** | ② 想定内の損失（仮説の検証材料） | ④ 明確な失敗（最優先で改善） |

### なぜ③が最も危険か

ルールを破って儲かると、脳は「ルールは不要」と学習する。
これが再現性を殺す。**③が出たときは、①より詳しく記事にする。**

これは金融リテラシーの本質そのもの：
**良い判断と良い結果は、別物である。**

---

## 6. 公開してよい記録 / 慎重に扱う記録

| 種類 | 扱い |
|---|---|
| 損益率（％） | 公開する |
| 判断の理由 | 公開する |
| ルール遵守の可否 | 公開する |
| 感情の記録 | 公開する |
| 総資産の絶対額 | 公開しない（安全上・比較を煽らないため） |
| 家族・第三者の資産情報 | 公開しない |

**％で公開する理由**：絶対額は「すごい/しょぼい」の比較を生み、再現性の話を消す。
％なら、読者は自分の規模に置き換えられる（＝基準4：再現性）。
