## 1. ブランド名

**金融リテラシー＝人として**

一つの投資手法を売るブランドではない。
人生を通して学び続ける、金融リテラシーのブランド。

---

## 2. 理念

金融リテラシーとは、お金儲けの知識ではない。
**人生の選択肢を増やすための教養**である。

学ぶべきは、次の5つすべて。

| 領域 | 問い |
|---|---|
| **稼ぐ** | 自分の労働と資本を、どう収入に変えるか |
| **守る** | 保険・税・制度・詐欺・インフレから、どう資産を守るか |
| **増やす** | 時間と複利を、どう味方につけるか |
| **使う** | お金を、何と交換するのが自分にとって価値か |
| **残す** | 次の世代・次の自分に、何を渡すか |

この5領域を扱うから、このブランドは投資だけを扱わない。
核にあるのは、**「人として、お金とどう向き合うか」**という問い。

---

## 3. ミッション

日本にはいまだに、こうした価値観が残っている。

- 学校では金融を学ばない
- 投資＝怖い
- お金の話はいやらしい

一方で現代は、AI・インフレ・新NISA・Bitcoin・世界経済など、
**お金の知識が人生に与える影響が年々大きくなっている**。

だからこそ、金融リテラシーを「投資の知識」ではなく、
**人生を生き抜く力**として伝える。

---

## 4. ビジョン

**「金融リテラシー＝人として」という言葉を、日本で一つのブランドに育てる。**

そのために、次の6領域を**一つの世界観**で発信する。

投資 / AI / 経営 / 資産形成 / 思考法 / 人生設計

> 判断基準：新しいテーマを扱うか迷ったら、
> 「これは"人として、お金とどう向き合うか"の話か？」を問う。
> Yesなら扱う。Noなら扱わない。ジャンルではなく、問いで線を引く。

---

## 5. ブランドポジション

### 名乗らないもの

- 投資のプロではない
- ファンドマネージャーではない
- 証券アナリストではない

### だから、しないこと

- 未来を断言しない
- 予想を売らない

### 名乗るもの

**実践者（Practitioner）**

一緒に学び、一緒に考え、一緒に金融リテラシーを身につけていく立場。

### ポジショニングマップ

```
                    断言する（予想を売る）
                            ▲
                            │
      権威型                │             煽り型
  （アナリスト・専門家）      │       （インフルエンサー・情報商材）
                            │
  情報を持つ ◄───────────────┼───────────────► 過程を見せる
                            │
      教科書型              │        ★ 金融リテラシー＝人として
   （制度解説・入門書）       │           （実践者・検証者）
                            │
                            ▼
                    断言しない（検証を見せる）
```

**空白地帯はここ**：
断言せず、過程を全部見せ、しかも仕組みまで渡す発信者は、日本にほとんどいない。
「当たった/外れた」の勝負をしないから、相場に左右されず10年続けられる。

## 6. ブランドの約束（Brand Promise）

このブランドは、次を約束する。

- 利益**だけ**を見せない
- 失敗を公開する
- 迷いを公開する
- 改善を公開する
- ルール変更は、**理由と一緒に**公開する

そして、結果だけでなく——

- **どう考えたのか**
- **なぜその判断をしたのか**

そこまで公開する。

> この約束は、`templates/decision-log.md` `templates/failure-log.md`
> `templates/rule-change-log.md` によって**運用可能な形**に落とし込まれている。
> 約束を「気持ち」ではなく「仕組み」で守るのが、このブランドの設計思想。

## 7. ブランドパーソナリティ

人格として言えば、こういう人。

| 軸 | そうである | そうではない |
|---|---|---|
| 姿勢 | 誠実・率直 | 謙遜しすぎ・自虐的 |
| 語り口 | 落ち着いている | テンションが高い・煽る |
| 立場 | 隣を歩く実践者 | 上から教える先生 |
| 判断 | 断定しない | 曖昧でごまかす |
| 数字 | 都合の悪い数字も出す | 良い数字だけ切り取る |
| 態度 | 変わったら理由を言う | 過去の発言をこっそり消す |

**「断定しない」と「曖昧」は違う。**
断定しないのは未来について。自分の判断とその理由については、はっきり書く。

### 断言の移設（→ `11_dialectic.md` 対立1）

断言をやめるのではない。**向ける先を変える。**

| 断言しない領域 | 断言する領域 |
|---|---|
| 市場・価格・未来 | 自分の原則・価値観・判断基準 |
| 「BTCは上がる」 | 「私は生活防衛資金には絶対に手を出さない」 |
| 「今が買い時」 | 「ルールを破って得た利益を、私は失敗と呼ぶ」 |

予測を断言する人は、外れた瞬間に信用を失う。
原則を断言する人は、守り続ける限り信用が増え続ける。

**強い言葉を捨てない。強い言葉を、正しい対象に向ける。**

## 8. 読者（誰に届けるか）

### コア読者：「学びたいが、始め方がわからない30〜40代」

- 新NISAは知っているが、何に投資するか自分で決められない
- 投資系の発信は見るが、煽りが強くて信用できない
- 「儲かる方法」ではなく「判断できる自分」がほしい
- 仕事・家庭があり、専業トレーダーにはなれない

### 副次読者

- 経営者・個人事業主（Project 04 につながる）
- 20代の学び始め層（長期でコア読者に育つ）

### この人たちが本当に欲しいもの

情報ではない。**「自分で決めた」と言える根拠**である。
だから、有料コンテンツは答えではなく**判断の仕組み**を売る（→ `07_monetization.md`）。

## 9. ブランド構成

```
ブランド：金融リテラシー＝人として
│
├── Project 01：BTCサイクル積立プロジェクト        ［稼働中］
├── Project 02：AI資産管理プロジェクト             ［将来］
├── Project 03：新NISA実践プロジェクト             ［将来］
└── Project 04：経営者のお金の教養                 ［将来］
```

各プロジェクトは**ブランドの子**であり、独立ブランドではない。
プロジェクトが終わってもブランドは残る。この構造が10年続く理由。

## 10. スローガン

**金融リテラシーは、お金の知識ではない。**
**人生の選択肢を増やす力である。**

### 用途別の短縮形

| 用途 | 表記 |
|---|---|
| 正式スローガン | 金融リテラシーは、お金の知識ではない。人生の選択肢を増やす力である。 |
| プロフィール一行 | 予測を手放し、規律を掲げる。実践者としての金融リテラシー。 |
| 締めの定型句 | 人として、どう判断したか。 |

締めの定型句は毎回同じ言葉を使う。**反復が記憶になり、記憶がブランドになる。**

## 11. 呼称設計（→ `11_dialectic.md` 対立8）

ブランド名には2つの機能がある。**1つの文字列に両方を負わせない。**

| 機能 | 担うもの | 用途 |
|---|---|---|
| **旗**（理念を宣言する） | 金融リテラシー＝人として | 見出し・About・書籍・商品・正式表記 |
| **呼称**（人が口にする） | **人として** | 会話・シリーズ名・締め・ハンドル・URL |

### 運用ルール

- **正式名は変えない。** これは理念の旗であり、短縮のために削らない。
- 短縮形は**自分で名乗らない。市場に育てさせる。**
- 締めの定型句「人として、どう判断したか。」を全コンテンツで反復し、短縮形を刷り込む
- ハンドル・URL・シリーズ名は短縮形ベースで統一する

> 名前は付けるものではなく、**呼ばれて定着するもの**。
> 3年後、読者が短縮形で呼び始めたら、ブランド化は成功している。
> （KPI「指名検索数」は、この短縮形でも計測する → `09_kpi.md`）
