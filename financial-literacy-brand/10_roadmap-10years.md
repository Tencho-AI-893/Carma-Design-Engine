# 10. 10年ロードマップ

**10年計画の目的は、10年後を当てることではない。**
**「今、焦らなくていい理由」を自分に与えることである。**

---

## フェーズ全体像

```
Phase 1 (Y1)      Phase 2 (Y2-3)     Phase 3 (Y4-5)     Phase 4 (Y6-10)
 記録を作る    →    仕組みを売る   →   体系にする    →   ブランドになる
    │                  │                  │                  │
 信頼の土台         事業の成立         再現性の証明        言葉の定着
```

---

## Phase 1：記録を作る（Year 1）

**このフェーズの唯一の仕事：12ヶ月、記録を途切れさせない。**

| やること | やらないこと |
|---|---|
| Project 01 の事前ルール公開 | 収益化 |
| 月次レポート12回 | 新プロジェクトの追加 |
| 教養コンテンツの土台作り | 規模の追求 |
| 失敗ログの型の確立 | 時事への過剰反応 |

**移行条件**：月次レポート12回連続公開 ＋ 失敗ログが1件以上ある

> 失敗ログが0件のまま1年が過ぎたら、それは「失敗していない」のではなく
> **「失敗を書けていない」**。ブランドの約束が機能していない危険信号。

---

## Phase 2：仕組みを売る（Year 2–3）

**1年分の記録を、再現可能な仕組みに変換する。**

| やること | 判断ポイント |
|---|---|
| 実践マニュアル・テンプレートの商品化 | 「答え」でなく「仕組み」か（`07`§3） |
| Project 02（AI）または 03（新NISA）の開始 | 起動条件を満たしたか |
| プラットフォームの母艦化（ブログ/note） | SNS依存を減らせているか |
| メルマガ等、直接届く経路の構築 | 読者との関係が深まっているか |

**移行条件**：月次レポート36回 ＋ 有料商品のリピート購入が発生している

---

## Phase 3：体系にする（Year 4–5）

**Project 01 が4年サイクルを一周する。ブランド最大の山場。**

| やること | 意味 |
|---|---|
| Project 01 の4年総括（48ヶ月の全記録） | **このブランド最大の資産の完成** |
| 運用OS・ダッシュボードの提供 | 仕組みの完成形 |
| 書籍化・講演等の外部展開 | 権威ではなく「記録」で外に出る |
| 次の4年サイクルの仮説を公開 | 継続の宣言 |

### 4年総括で最も価値があるのは

「儲かったか」ではなく、**「4年間、ルールを守り続けた人間の記録」**そのもの。
これを日本語で持っている実践者は、ほとんどいない。

**移行条件**：4年総括の公開 ＋ 指名検索が観測されている

---

## Phase 4：ブランドになる（Year 6–10）

**「金融リテラシー＝人として」が、個人名より先に想起される状態へ。**

| やること | 到達イメージ |
|---|---|
| 4プロジェクトすべての稼働 | 5領域を網羅した世界観 |
| 教育・コミュニティへの展開 | 学ぶ人が学ぶ人を育てる |
| 第2サイクルの検証記録 | 「一度きり」でないことの証明 |
| 言葉の定着 | ブランド名が普通名詞のように使われる |

---

## フェーズ共通の禁止事項

各フェーズで、**焦りから出やすい行動**を先に禁止しておく。

| フェーズ | 焦ると起きること | 禁止 |
|---|---|---|
| Phase 1 | 反応がなくて収益化を急ぐ | Year 1 での本格収益化 |
| Phase 2 | 売れて調子が出て手を広げる | 3プロジェクト以上の同時稼働 |
| Phase 3 | 実績が出て断定的になる | 「実践者」ポジションからの逸脱 |
| Phase 4 | 規模のために理念を薄める | 8つの判断基準を通さない企画 |

---

## 10年後の判定基準

10年後、次の問いに「はい」と言えれば成功。

- [ ] 記録は途切れなかったか
- [ ] 失敗を公開し続けたか
- [ ] 一度も未来を断言しなかったか
- [ ] 読者は「自分で判断できる」ようになったか
- [ ] 「金融リテラシー＝人として」という言葉が残ったか

**この5つに、利益額は入っていない。**
それが、このブランドの正体である。
